INFORMASI LAYANAN

Kebijakan Privasi.

Data yang diproses

Gomi memproses ID sesi acak, preferensi negara yang kamu pilih, data teknis koneksi, pesan teks selama sesi, serta laporan keselamatan. Pemeriksaan tanggal lahir untuk age gate dilakukan di browser dan tanggal lahir tidak dikirim atau disimpan oleh Gomi. Gomi tidak meminta akses GPS.

Video dan audio

Audio dan video dikirim langsung antar perangkat menggunakan WebRTC. Server Gomi menangani pencocokan dan pertukaran sinyal koneksi. Gomi tidak merekam atau menyimpan audio maupun video. Kualitas koneksi dapat memerlukan server TURN untuk meneruskan paket media, tetapi konfigurasi standar tetap tidak merekam media.

Laporan dan blokir

Laporan menyimpan ID sesi pelapor dan terlapor, alasan, keterangan yang kamu kirim, waktu, dan status penanganan. Data ini digunakan untuk moderasi dan keamanan.

Penyimpanan lokal

ID sesi disimpan di penyimpanan lokal browser agar fitur blokir dapat bekerja lintas kunjungan pada perangkat yang sama. Menghapus data situs akan membuat ID sesi baru.

Batasan

Jangan membagikan informasi rahasia. Pengguna lain dapat merekam layar atau mengambil tangkapan layar dengan perangkatnya sendiri; Gomi tidak dapat mencegah tindakan tersebut.
